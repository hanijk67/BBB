> تسک 21. هر سناریو را شما اجرا می‌کنید و ستون «نتیجه» را پر می‌کنید (✅ / ❌ / ⚠️ + توضیح). هر رشته‌ی

> مرورگرها: Chrome دسکتاپ (S)، Firefox دسکتاپ (D1)، Chrome یا Safari موبایل (D2).

## فاز ۵ — سناریوی کامل از UI LMS

**L1 — ورود فقط از UI LMS.** هیچ URLی دستی تایپ نشود.
1. S وارد LMS → پنل → آموزش → درس‌های من → درس → تب «کلاس آنلاین» → «مدیریت کلاس آنلاین».
2. نکته‌ی «اسلایدها را PDF آپلود کنید» دیده شود. «شروع کلاس آنلاین» → تب جدید، S داخل کلاس به‌عنوان مدیر.
3. صفحه‌ی LMS (بعد از حداکثر ۳۰ ثانیه) نشانگر «در حال برگزاری» دارد.
4. D1 از داشبورد → بنر «کلاس زنده» → «ورود به کلاس» → تب جدید، داخل کلاس به‌عنوان شرکت‌کننده؛ نامش همان نام
   پروفایل LMS است.
5. D2 روی موبایل همین کار را از داشبورد یا لینک اعلان (صفحه‌ی `/panel/classes/<id>`) انجام دهد.

معیار: هر سه داخل یک کلاس، UI فارسی (`userdata-bbb_override_default_locale=fa-IR`)، صدا و تصویر برقرار.

**L2 — دانشجو قبل از شروع.** کلاس شروع‌نشده؛ D1 «ورود به کلاس» → پیام «کلاس هنوز توسط استاد شروع نشده —
هر ۳۰ ثانیه دوباره بررسی می‌شود». S کلاس را شروع کند → حداکثر ۳۰ ثانیه بعد دکمه‌ی D1 به «کلاس شروع شد — ورود»
تبدیل شود و ورود کار کند.

**L3 — مجوزها.** با یک حساب استاد دیگر (مدرس کلاس دیگر) از Swagger gateway:
`POST /api/v1/virtual-classes/<id>/start`، `/end`، `PATCH /<id>/settings` → همه 403. یک دانشجوی ثبت‌نام‌نشده:
`GET /<id>/join` و `/<id>/recordings` → 403.

**L4 — پایان و خروج.** S «پایان کلاس» → تأیید → همه از کلاس بیرون؛ BBB هر کاربر را به
`/panel/classes/<id>/left` («از کلاس خارج شدید») می‌برد. نشانگر «در حال برگزاری» حذف شود.

**L5 — ضبط‌ها.** کلاسی که حداقل ۵ دقیقه ضبط داشته (M6). بعد از پایان:
1. در صفحه‌ی کلاس (S و D1) ضبط با «در حال آماده‌سازی ضبط» ظاهر شود (callback meeting-ended).
2. چند دقیقه بعد «پخش» فعال؛ تاریخ شمسی و مدت درست.
3. «در حال آماده‌سازی فایل ویدئو» → بعداً «دانلود ویدئو»؛ فایل mp4 روی iPhone/Android پخش شود.
4. S روی یک ضبط «مخفی» → D1 دیگر آن را نبیند؛ «نمایش» → برگردد. «حذف» → از لیست و از `published/` حذف شود.

**L6 — ویدئو خاموش (T7).** S تیک «ساخت فایل ویدئویی از ضبط» را بردارد → کلاس را شروع، ۵ دقیقه ضبط، پایان.
معیار: در LMS برای این ضبط هیچ دکمه یا پیام «ویدئو» نیست؛ روی سرور فقط
`/var/bigbluebutton/published/presentation/<recordID>` ساخته شده و `published/video/<recordID>` وجود ندارد.

**L7 — حضور و غیاب.** بعد از L4، تب «حضور و غیاب» در صفحه‌ی استاد: D1 و D2 با نام، ورود/خروج و مدت حضور
(تقریبی، دقیقه) و زمان صحبت. callback تکراری (اجرای دوباره‌ی
`ruby /usr/local/bigbluebutton/core/scripts/post_events/post_events_analytics_callback.rb -m <recordID>`) ردیف
تکراری نسازد.

## فاز ۶ — مدیریت کلاس توسط استاد (built-in BBB)

| # | قدم‌ها | معیار |
|---|---|---|
| M1 | S، D1 وارد شوند | S مدیر (MODERATOR)، D1 شرکت‌کننده (VIEWER)؛ D1 گزینه‌های مدیریتی ندارد |
| M2 | D1 وارد شود؛ S «بستن صدای همه» و «همه به جز ارائه‌دهنده» | D1 بی‌صدا وارد می‌شود (`muteOnStart`)؛ هر دو گزینه کار کند |
| M3 | S → قفل کاربران: وبکم، میکروفون، چت عمومی، چت خصوصی، یادداشت، دیدن لیست کاربران — هر کدام جدا | D1 هر مورد قفل‌شده را نمی‌تواند استفاده کند؛ باز کردن قفل برگرداند |
| M4 | S: اخراج D2 / دادن و گرفتن ارائه‌دهنده و مدیر به D1 | هر عمل فوراً اعمال شود؛ D2 اخراج‌شده دوباره نتواند با همان لینک وارد شود |
| M5 | (فقط اگر لازم است) `BBB_DEFAULT_GUEST_POLICY=ASK_MODERATOR` | ورود D1 منتظر تأیید S بماند |
| M6 | S دکمه‌ی ضبط → شروع، توقف موقت، ادامه | بدون شروع خودکار (`autoStartRecording=false`)؛ دکمه کار کند |
| M7 | D1 داخل کلاس؛ S ضبط را شروع کند؛ بعد D2 وارد شود | D1 و D2 هر دو دیالوگ اعلان ضبط با متن فارسی «این جلسه ضبط می‌شود و ضبط آن در سامانه برای دانشجویان کلاس قابل مشاهده است.» ببینند |
| M8 | آپلود اسلاید، وایت‌برد، اشتراک صفحه، ویدئوی خارجی، نظرسنجی، تایمر، اتاق جانبی | همه کار کند و UI فارسی |
| M9 | چت عمومی + خصوصی، پین پیام، پاک کردن چت، ذخیره‌ی چت | همه کار کند؛ برچسب‌ها فارسی |
| M10 | S → Learning Dashboard | باز شود، فارسی، داده‌ی D1/D2 |

## فاز ۳ — فارسی، RTL، فونت

**F1 — UI کاملاً فارسی.** در کلاس با زبان فارسی، همه‌ی پنل‌ها را باز کنید: لیست کاربران، چت (عمومی، خصوصی،
پین)، قفل‌ها، ضبط، صدا (تنظیمات صدا، فیلتر نویز)، تنظیمات، میان‌برها، breakout، نظرسنجی/آزمونک، تایمر،
یادداشت، گالری برنامه‌ها، Learning Dashboard. معیار: **هیچ** رشته‌ی انگلیسی (به جز نام‌های خاص مثل PDF،
Markdown، YouTube). هر رشته‌ی انگلیسی → کلید آن را در `en.json` پیدا کنید (جستجوی متن) و ترجمه کنید.

**F2 — RTL.** چیدمان راست‌به‌چپ؛ آیکون‌های جهت‌دار (فلش‌ها) درست؛ فونت Vazirmatn (DevTools → Computed →
font-family روی body و Rendered Fonts).

**F3 — تغییر زبان.** تنظیمات → زبان → English → UI انگلیسی و LTR؛ Deutsch → آلمانی؛ برگشت به فارسی → RTL و
فونت فارسی برگردد.

**F4 — چت.** در UI فارسی پیام‌های: «سلام»، `Hello`، «سلام hello ۱۲۳»، `test سلام 123`، یک لینک
`https://glmp.ir`. همین‌ها در UI انگلیسی. معیار: هر پیام از سمت زبان اولین حرفش چیده شود (فارسی راست، انگلیسی
چپ)، عدد و لینک جابه‌جا نشود (`unicode-bidi: plaintext` در `custom.css`). کادر نوشتن پیام هم همین‌طور.

**F5 — اسلاید فارسی (T4).** طبق `tools/test-slides/README.md` (PPTX با B Nazanin/B Titr/IRANSans، DOCX با
B Lotus/B Mitra، PDF). معیار همان فایل.

**F6 — بدون دامنه‌ی خارجی (T5).** DevTools → Network → Disable cache → ورود به کلاس و چند دقیقه کار. فیلتر:
`-domain:class.glmp.ir -domain:turn.glmp.ir -domain:glmp.ir`. معیار: لیست خالی (هیچ فونت/CDN/اسکریپت خارجی).
WebSocket و WebRTC (به TURN) مجازند.
