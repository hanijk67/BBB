# تست تبدیل اسلاید فارسی (T4)

فایل‌های تستی (PPTX/DOCX) در ریپو commit نمی‌شوند؛ خودتان با PowerPoint/Word بسازید و همین‌جا
(یا هر جای دیگر) نگه دارید. فقط این راهنما در ریپو است.

## پیش‌نیاز روی سرور BBB

```bash
fc-list | grep -i vazirmatn                 # Regular/Medium/Bold باید دیده شوند
fc-match "B Nazanin"                        # باید Vazirmatn برگرداند
fc-match "IRANSans"                         # باید Vazirmatn برگرداند
ls /etc/fonts/conf.d/99-lms-fa.conf
```

اگر `fc-match` چیز دیگری داد: `sudo /etc/bigbluebutton/bbb-conf/apply-config.sh` و دوباره چک کنید.

## فایل‌های تست

| # | فایل | محتوا |
|---|---|---|
| 1 | `test-bnazanin.pptx` | ۳ اسلاید: عنوان با **B Titr**، متن با **B Nazanin**، یک اسلاید با **IRANSans**؛ متن مخلوط فارسی/انگلیسی، عدد (۱۲۳ و 123)، فهرست شماره‌دار، جدول ۲×۳ |
| 2 | `test-fa.docx` | یک صفحه متن فارسی با B Lotus و B Mitra، تیتر، پاراگراف چندخطی، پرانتز و علامت سؤال |
| 3 | `test-fa.pdf` | همان PPTX شماره ۱ که در PowerPoint با «Save as PDF» (فونت embed) خروجی گرفته شده |

## روش تست

1. یک کلاس تستی بسازید و به‌عنوان ارائه‌دهنده وارد شوید.
2. هر سه فایل را از «بارگذاری ارائه» آپلود کنید.
3. منتظر تبدیل بمانید؛ در صورت خطا: `journalctl -u bbb-web -n 100` و `/var/log/bigbluebutton/`.
4. هر اسلاید را با نسخه‌ی اصلی مقایسه کنید.

## معیار پذیرش

- [ ] هیچ مربع (□) یا علامت سؤال به جای حرف نیست.
- [ ] حروف فارسی **متصل** هستند (نه جدا و تک‌تک).
- [ ] جهت متن راست‌به‌چپ است؛ نقطه، پرانتز و عدد در جای درست.
- [ ] PPTX و DOCX با Vazirmatn رندر شده‌اند (طبیعی است ظاهرش با B Nazanin فرق کند).
- [ ] PDF دقیقاً مثل اصل است (فونت embed شده و از LibreOffice رد نمی‌شود).
- [ ] اگر چیدمان PPTX به‌خاطر جایگزینی فونت به‌هم ریخت (متن از کادر بیرون زد، شکست سطر عوض
      شد) → این قابل قبول است و راه‌حل، توصیه‌ی «اسلاید را PDF کنید» در پنل استاد LMS است (فاز ۵).

نتیجه را در `lms-integration/deploy/ACCEPTANCE.md` (تسک 21) ثبت کنید.
